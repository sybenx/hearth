threshold vectors

Known answers for NKM §7's dealing, share checking, signing and rotation, from frost-vectors.json — the specification’s own normative vector file, copied rather than regenerated here. It runs against whatever is behind frost.js, so a build that swapped the implementation underneath has to reproduce every value below before it is trusted with anybody’s key.

The fixture identity has an odd-y pubkey on purpose. §7.4's parity rule is the only behaviour in either document that depends on key parity, and both a key and its negation serialise to the same x-only pubkey — so an even-y fixture would pass whichever reading of §7.4 an implementer took, and so would §7.5's own check. Two of the answers below are deliberately false: §7.18 offers t = 3 and states a share check that does not hold there, and reproducing the false is what shows the section was read rather than skimmed.
